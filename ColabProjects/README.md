
OPTIMIZING HAZARDOUS WASTE MANAGEMENT FACILITIES IN THE PHILIPPINES: 
ADDRESSING REGIONAL DISPARITIES
This project aims to analyze the total hazardous waste generated by various regions in the country and compare it with the number of registered Treatment, Storage, and Disposal (TSD) facilities. By examining this relationship, we can determine whether there is a complementary balance between waste generation and facility availability. This analysis will highlight potential gaps and inconsistencies in hazardous waste management across the Philippines, guiding strategies for enhancement and sustainability.
