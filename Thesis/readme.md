# Development Of a Mobile Application for Tricycle: Distance Tracking, Fare Calculation, and Overpricing Reporting

## Abstract

Tricycles remain one of the most common and accessible modes of public transportation, especially in provincial towns and municipalities. For many commuters, tricycles are the daily link between home, school, work, and essential services. However, despite their importance, challenges such as inconsistent fare pricing affect the commuting experience. Hence, this study aimed to develop a mobile application for tricycles that could track distance travelled, calculate fares, and report complaints of overpricing.

Using location services on a mobile smartphone, the application could track distance in real time. The fare calculation was based solely on the administrator's fare configuration, and Firebase served as the backend for storing reports. Developmental research was used to design a mobile application that automatically calculates the fare based on the suggested route and generates digital reports.

Evaluation through testing and surveys yielded high ratings for the design, usability, accuracy, and performance of the whole system. The implementation enhanced the passenger experience by providing consistent fare pricing in tricycle operations. This innovation showed that mobile technology could address problems in the transportation sector.

**Keywords:** application, fare, integration, reporting, tracking
